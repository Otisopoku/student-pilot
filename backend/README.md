# Backend

Initial backend directory scaffold for Student Pilot. The folders are intentionally framework- and language-neutral; add implementation files as the backend technology is decided.

```text
backend/
├── src/
│   ├── config/       # Environment and service configuration
│   ├── controllers/  # Request handlers
│   ├── middleware/  # Shared request/response middleware
│   ├── models/      # Data models and persistence layer
│   ├── routes/      # API route definitions
│   ├── services/    # Application and business logic
│   └── utils/       # Shared helpers
└── tests/           # Backend tests
```
